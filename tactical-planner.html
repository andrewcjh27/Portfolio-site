How to use
  • Switch tools with the buttons or keys V/X/O/A.
  • Add X / Add O: click anywhere on the canvas to drop a marker.
  • Add Arrow: click the source marker, then click the target — the curve auto-fits.
  • Select: click a marker or arrow. Drag markers to reposition. For a selected arrow, drag its blue handle to bend the curve.
  • Delete selected item with Delete or Backspace.
  • Switch sections at the top — each one has its own state, kept independently.
