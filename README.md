# Portfolio Site

Personal portfolio website showcasing projects in software engineering, design, and data science. Built as a static site with vanilla HTML/CSS/JS and scroll-driven animations.

## Sections

- **Homepage** — animated hero with project highlights and scroll-triggered transitions
- **Design** — 3D, art, and UI/UX galleries with cursor-tilt carousel
- **Cafes** — Seoul cafe explorer with Naver Maps integration and searchable list
- **Soccer AI** — chat interface for an AI soccer coach, backed by a Python server
- **Experience** — professional experience and resume

## Tech Stack

- HTML / CSS / JavaScript
- Python (chat server)
- Naver Maps API

## Running Locally

Open `index.html` in a browser. For the soccer chat feature, start the server:

```bash
python soccer_chat_server.py
```
