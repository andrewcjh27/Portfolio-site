01 — What I build

Code as a way
to ask questions.

Most of my projects start as a question I want a concrete answer to — can a model predict heart disease from clinical data, can a 3D U-Net segment a tumor, can a tiny iOS widget fit a whole to-do list on a Lock Screen. The repos below are my attempts.

Languages range across Python, Java, Swift, and the usual web stack. Some are coursework, some are research, some are weekend builds — but each one taught me something I couldn’t have learned by reading.
