Gallery layout planner

Sketch a panel grid below, see it rendered on the right, then copy the CSS into photo.html when you're happy.

Cell names you can use:
c1 c2 c3 = city / nature / cafe photos (tall)
w1 w2 = water / bottom photos
lc lw ln = labels (city / water / nature)
. = empty cell (creates negative space)

Rules: adjacent cells with the same name merge into one area. Each area must be a rectangle.
